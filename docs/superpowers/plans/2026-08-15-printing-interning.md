# Printing Interning Implementation Plan (#1592)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Objects name a printing by id instead of carrying a whole `Card`, via a game-local intern table in `GameState`.

**Architecture:** A `Map PrintingId Printing` in `GameState` beside the existing `nextObjectId`/`nextTimestamp` counters. `Source.OfCard`/`OfToken`/`OfEmblem` and `Player.commander`/`dungeon` carry a `PrintingId`. Printings enter a game at exactly two places — `Setup.createDeck` (from the registry-built `Deck`) and `Event`'s token and emblem minting — and both already intern once and create many. Ids are minted only by insertion, so an id naming nothing is unconstructible.

**Tech Stack:** GHC / Haskell, cabal, tasty. No new dependencies.

```haskell
freshPrintingId :: GameState -> (PrintingId.PrintingId, GameState)
freshPrintingId gs =
  let PrintingId.MkPrintingId n = GameState.nextPrintingId gs
   in (PrintingId.MkPrintingId n, gs {GameState.nextPrintingId = PrintingId.MkPrintingId (n + 1)})

-- Put a printing in the table and answer with the id that names it. The ONLY
-- way to get a PrintingId, which is what makes a dangling one unconstructible.
--
-- Deliberately not deduplicating: both callers already intern once and create
-- many -- Setup.internDeck over a deck's distinct entries, Event over one
-- token-creation event's count -- so a reverse index would pay the deep
-- Ord Card this change exists to avoid, at every intern, to save entries the
-- call sites do not generate.
intern :: Printing.Printing -> GameState -> (PrintingId.PrintingId, GameState)
intern printing gs =
  let (pid, gs1) = freshPrintingId gs
   in (pid, gs1 {GameState.printings = Map.insert pid printing (GameState.printings gs1)})

printingOf :: PrintingId.PrintingId -> GameState -> Maybe Printing.Printing
printingOf pid gs = Map.lookup pid (GameState.printings gs)
```

```haskell
-- Every distinct printing a deck names, interned once, so the copies of a 4-of
-- share one id and the commander's id is the same one its 99 would use if the
-- deck were malformed enough to list it twice (#940 does not enforce CR 903.5).
-- Local to building one deck: the deep Ord Printing is paid once per game here
-- and never again, which is the trade Game.intern declines to make globally.
internDeck :: Deck.Deck -> Game (Map.Map Printing PrintingId.PrintingId)
internDeck deck =
  let distinct = Map.keys (Deck.cards deck) <> Maybe.maybeToList (Deck.commander deck) <> Maybe.maybeToList (Deck.dungeon deck)
   in Monad.foldM
        ( \acc printing ->
            if Map.member printing acc
              then pure acc
              else do
                gs <- State.get
                let (pid, gs1) = Game.intern printing gs
                State.put gs1
                pure (Map.insert printing pid acc)
        )
        Map.empty
        distinct
```

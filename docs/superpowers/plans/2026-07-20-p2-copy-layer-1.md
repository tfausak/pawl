# M4.5 P2 — Copy (layer 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement permanent copy (CR 707) as a projected layer-1 characteristic, gated by Clone, so a permanent that enters as a copy of another permanent projects that permanent's copiable values — the M4.5 go/no-go.

**Architecture:** A copy is a **snapshot of the copied object's copiable values, taken as the object enters and stored in its `bindings`**. The projection's layer fold is **seeded** with that snapshot (layer 1) instead of the printed characteristics; layers 2–7 fold on top. The as-enters choice is a **pure mark** in the battlefield-entry funnel (`Event.placeObject`) plus a **monadic drain** at the CR 117.5 settle boundary (`Engine.settleForPriority`), run before triggers and state-based actions. Zero new opcodes.

**Tech Stack:** Haskell 2010 (GHC 9.14.1 via Nix), `tasty` (`tasty-hunit` + `tasty-quickcheck`), hand-rolled JSON codec. Cards are `data/cards/*.json` loaded by the test suite.

```haskell
-- CR 707.9a: the reserved slot under which an object's copy snapshot is stored

copySource :: SlotName
copySource = SlotName.MkSlotName (Text.pack "copySource")

-- CR 614.1c / 603.6d: the reserved slot marking that an object that entered as a
-- copy has not yet made its as-enters choice (P2). Set by Event.placeObject,
-- drained at the CR 117.5 boundary by Engine.drainAsEntersChoices.
asEntersPending :: SlotName
asEntersPending = SlotName.MkSlotName (Text.pack "asEntersPending")

-- The copy snapshot stored on an object, if any (CR 707.2).
copyOf :: Map SlotName Binding -> Maybe ProjectedCharacteristics
copyOf m = Binding.copy =<< Map.lookup copySource m

-- Store a copy snapshot under the reserved copySource slot (P2).
setCopy :: ProjectedCharacteristics -> Map SlotName Binding -> Map SlotName Binding
setCopy pc = Map.insert copySource (Binding.empty {Binding.copy = Just pc})

pendingCopy :: Map SlotName Binding -> Bool
pendingCopy = Map.member asEntersPending

-- Mark an as-enters copy choice pending (Event.placeObject).
markPending :: Map SlotName Binding -> Map SlotName Binding
markPending = Map.insert asEntersPending Binding.empty

clearPending :: Map SlotName Binding -> Map SlotName Binding
clearPending = Map.delete asEntersPending
```

```haskell
-- CR 707.2 / 613.1a: an object's layer-1 (copy) result -- the value the layer fold
-- STARTS from. If the object carries a copy snapshot in its bindings (stamped as it
-- entered, CR 707.9a, by Engine.drainAsEntersChoices), that snapshot IS its copiable
-- value; otherwise it is the printed base. Only base-or-snapshot, so counters (7c),
-- pumps (7c), control (2), and ability grants (6) -- all folded ABOVE this -- are
-- never part of a copied object's own copiable value (the P2 falsifier, made
-- structural). Not a recursion: a copy of a copy stores the underlying creature's
-- values at entry, so the snapshot is already resolved.
copiableCharacteristics :: ObjectId -> GameState -> ProjectedCharacteristics
copiableCharacteristics oid gs =
  case Game.lookupObject oid gs >>= (Binding.copyOf . Object.bindings) of
    Just snapshot -> snapshot
    Nothing -> baseCharacteristics oid gs
```

```haskell
-- marker, resolving its choice AT the CR 117.5 boundary but BEFORE state-based
-- actions and triggers (settleForPriority calls this first). This is observably

drainAsEntersChoices :: Game Bool
drainAsEntersChoices = do
  gs <- State.get
  let pending = filter (isPending gs) (Set.toList (GameState.battlefield gs))
  Monad.mapM_ drainOneCopy pending
  pure (not (null pending))

drainOneCopy :: ObjectId -> Game ()

          legal = Target.legalCopyTargets oid gs
      chosen <- Trans.lift (Program.prompt (Prompt.ChooseCopyTarget decider controller oid legal))
```

Clone A copies a Piker; Clone B copies Clone A (the most-recently-entered, so `copyNewest` picks A). B must resolve to a 2/1 Piker — proving B copied A's baked snapshot, not A's live base 0/0:

```haskell

        let gs0 = Setup.emptyGame S.bothPlayers
            (_, board) = S.addPiker cards S.alice gs0
```

- [ ] **Step 4: Write the source-leaves scenario (the snapshot payoff)**

Clone copies a Piker; the Piker is then destroyed; the Clone stays a 2/1 (the snapshot is locked, CR 707.9a — a live-ObjectId model would revert it to 0/0):

```haskell
      HU.testCase "a copy survives its source leaving the battlefield (CR 707.9a lock)" $
        let gs0 = Setup.emptyGame S.bothPlayers
            (pikerId, board) = S.addPiker cards S.alice gs0
            (_, staged) = S.spellOnStack (Cards.clonePrinting cards) S.alice board
            resolved = resolveAndSettle copyNewest staged
            afterKill = Event.destroy pikerId resolved
         in case cloneOnBattlefield afterKill of
              Nothing -> HU.assertFailure "Clone should survive the source's death"
              Just cloneId -> do
                HU.assertEqual "the source is gone" False (Set.member pikerId (GameState.battlefield afterKill))

                HU.assertEqual "the Clone is still 1 toughness" (Just 1) (Projection.toughnessOf cloneId afterKill)
```

(`Event.destroy` is pure `GameState -> GameState`; the Piker is not indestructible, so it goes to the graveyard.)

Run: `cabal test --test-options='-p "/survives its source leaving/"' 2>&1 | tail -20`

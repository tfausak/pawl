# Ante unit 1: the zone — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land unit 1 of the ante spec: the ante zone (CR 400.1, 400.2), the `GameSettings` ante option (CR 407.1), CR 407.2's setup ante, CR 407.4's owner-only ante action, CR 800.4n's departure exception and CR 407.3's outside-the-game bar, proved by Contract from Below, Demonic Attorney, Rebirth, Jeweled Bird and Amulet of Quoz. It does not close #249.

**Architecture:** `Zone.Ante` is a shared, public zone held in `GameState.ante :: Set ObjectId`, built on the same pattern as `exile` and `command`. A new open-half opcode, `Effect.Ante` (payload `Pawl.Types.Ante`: player, ref, optional slot), antes the named objects that the named players own, through `Event.changeZonesTogether`. It is never a `MoveToZone` to `Zone.Ante`; Divergence 1 below says why. The setup step lives in `Pawl.Engine.Setup` beside `claimStartingPlayer`. The outside-the-game bar is one pure predicate in a new `Pawl.Engine.Ante`, which reads a printed `Face.anteOnly` flag and never the Oracle text.

**Tech Stack:** Haskell (GHC via the repo's nix flake), cabal, tasty.
**Spec:** docs/superpowers/specs/2026-10-08-ante-design.md

## Review Focus

These are the five input classes most likely to bite. Each has a test in its owning task.

1. **An empty or one-card library at setup ante.** An empty library antes nothing and asks nothing. A one-card library antes that card without a `RandomObject` prompt. Test: Task 4, "CR 407.2 an empty library antes nothing and a one-card library is not asked".
2. **Karn restart re-anteing.** `startGameFromCards` rebuilds the libraries from every card, ante cards included (CR 727.2). 3. **Two seats against three, and a player with no library in a subgame.** Every seat antes from its own library, in turn order from the starting player. A Shahrazad subgame seat whose main-game library was empty antes nothing and does not crash. Tests: Task 4, "CR 407.2 three seats each ante one card of their own, in turn order" and "CR 729.2/407.2 a subgame seat with no library antes nothing".
4. **Hidden to public.** A card anted off the top of a hidden library becomes a public object at once. `Game.isHiddenZone Zone.Ante` is False, and `Event.eventBindings` binds CR 400.7e's `became` for a move into the ante. 5. **Per-seat impossibility (CR 608.2d).** A Rebirth seat with an empty library cannot choose to ante, so it is not asked and its life does not become 20. An Amulet of Quoz target with an empty library cannot ante, so "If they don't" holds and the coin is flipped. Tests: Task 9, "CR 608.2d Rebirth does not ask a seat with an empty library, and its life stays"; Task 11, `data/scenarios/ante/ante-amulet-of-quoz-empty-library-flips.json`.

## Divergences from the spec (decided here; the PR body repeats them)

1. **`Effect.Ante`, not `MoveToZone` to `Zone.Ante`.** The spec refuses a `MoveToZone` "for an object whose owner is not the instruction's player". `MoveToZone` carries no player. The only candidate is the resolving controller, and that breaks three of the five cards. Demonic Attorney's "Each player antes the top card of their library" would refuse bob's card. Rebirth's "Each player may ante" and Amulet of Quoz's "Target opponent may ante" would refuse every card except the controller's own. CR 407.4 makes the anteing player part of the instruction, so the opcode carries it. A CardSpec lint forbids a `MoveToZone` into the ante (Task 6).
2. **The Jeweled Bird board uses Confiscate, not Control Magic.** Control Magic is "Enchant creature" (CR 702.5a), and Jeweled Bird is a noncreature artifact. Confiscate ("Enchant permanent. You control enchanted permanent."), already in `data/cards/`, is the printing that can take it.
3. **Rebirth needs CR 608.2d per seat.** The spec says Rebirth needs nothing new. But `Resolve.exercises` judges impossibility once for the whole clause, and it does so before `thoseWhoMay` is bound. So a seat with an empty library is asked, can accept, and would get 20 life without anteing. That is weaker in the player's favour. `PlayerRef.OwnerOfBound`, which the spec names, is `SlotArity.One` and cannot name each anteing player. Task 9 filters the asked seats per seat instead.
4. **`Companion.revealable`'s bar has no observer.** No companion is an ante card. Scryfall `o:"playing for ante" o:companion`, run by the implementer, is expected to return nothing. The line is kept because CR 407.3 states it, and it is marked at the site and in the PR as a regression fence.
5. **The docs edit is smaller than #249 says.** `docs/design.md` §6 already lists ante under ring 2 ("Paper extras", line 615), not "Possible but pointless". `docs/mtgish-gap-census.md` line 210 says "RING-2", not OOS. The final task updates only the census line.
6. **CR 800.4n reaches `Setup.funnelBack`.** The spec lists only `Departure.objectsLeaveWith`. But `funnelBack` detects a player who left inside a subgame by owner absence, and a departed owner's ante card that stays in the subgame defeats that test, losing their main-game library. Task 5 fixes both reads.
